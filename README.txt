# STC Sadguru Transport Company — Website

A responsive promotional website for a goods transport and logistics company.

## Files
- `index.html` — page content and sections
- `styles.css` — layout, colors, responsive design
- `script.js` — mobile navigation, call/WhatsApp buttons and quote enquiry form
- `assets/stc-homepage-banner.jpeg` — homepage banner supplied by the business owner

## Before publishing
1. Open `script.js`.
2. Replace `91XXXXXXXXXX` with the business WhatsApp number, including country code and digits only.
3. Add the phone number to `BUSINESS_PHONE`, for example `"+91 98765 43210"`.
4. Confirm that the company name, service list and service area are accurate.
5. The draft currently says the business is based in Solapur, Maharashtra. Change this if needed.
6. The quote form sends an enquiry through WhatsApp; it does not save submissions in a database.
7. Check that you have permission to use all business images and logos.

## Preview locally
Double-click `index.html` to open it in a browser. Keep the `assets` folder beside the HTML file.

## Publish free using GitHub Pages
1. Create a GitHub account at https://github.com/
2. Create a **public** repository, e.g. `stc-sadguru-transport`.
3. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder.
4. In repository Settings → Pages, select deployment from branch, choose `main` and `/ (root)`, then save.
5. Wait for the deployment URL to appear on the Pages settings screen.

Official guide: https://docs.github.com/en/pages/quickstart

## Google Search
After publishing, add the public URL to Google Search Console and request indexing. Search appearance and timing are not guaranteed.
